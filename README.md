# 📋 Enhanced To-Do List

A console-based To-Do List application developed using Java.

The application provides user authentication and complete task management with priorities, deadlines, recurring tasks, overdue tracking, sorting, and progress monitoring.

## 🚀 Features

### 👤 User Management

- User Registration
- User Login
- Forgot Password
- Email-based password recovery

### 📝 Task Management

- Add Tasks
- View Tasks
- Edit Tasks
- Remove Tasks
- Mark Tasks as Completed

### 📊 Task Organization

- Task Priority
  - LOW
  - MEDIUM
  - HIGH
- Task Deadlines
- Recurring Tasks
  - NONE
  - DAILY
  - WEEKLY
  - MONTHLY
- Overdue Task Tracking
- Sort Tasks by Priority
- Completion Progress Tracking

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- HashMap
- Enum
- LocalDateTime
- Java Collections
